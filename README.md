# Landing-Page-Pousada-Berkem
Website e Landing Page para o setor de hotelaria, focada em captação de reservas diretas.

Desenvolvimento da presença digital para a Pousada Berkem. O projeto foi estruturado para destacar a infraestrutura do local, passar credibilidade aos hóspedes e facilitar o processo de reserva direta, fugindo das altas taxas de plataformas de terceiros.

### Foco do Projeto
*   **Galeria Imersiva:** Exposição estruturada das acomodações e áreas de lazer.
*   **Design Clean e Convidativo:** Uso de psicologia das cores para transmitir conforto e descanso.
*   **Geração de Reservas (Leads):** Formulários e links diretos para atendimento rápido.
*   **SEO Local:** Estruturação de tags para ser facilmente encontrada no Google.

### Tecnologias Utilizadas
*   Front-end responsivo (HTML, CSS, JS / Frameworks)
*   Integração com API do Google Maps para localização
*   Otimização de performance web
